
# Localised AI Model for General Use

A personal project to learn web development, Python,
local AI models, and server administration.

## Project Goals

1. Create a self-hosted learning dashboard.
2. Track progress through 12 AI learning phases.
3. Build a webnovel refining and polishing assistant.
4. Run an AI language model locally on my PC.
5. Access the application from my phone.
6. Expand the system into a general-purpose AI assistant.

## Technology Stack

- HTML, CSS, JavaScript
- Python and Flask
- SQLite
- Ollama
- Git and GitHub

## Current Progress

Development Stage 1: Git and GitHub Fundamentals

## Development Approach

Learn each concept, implement it, test it,
and commit the working code.
